# The Hair Patch Studio — Hairise layout

Website for The Hair Patch Studio — specialist non-surgical hair replacement in London. Version on the Hairise layout.

- `site/` — the static website (open `site/index.html`, or deploy the folder as-is). Vercel serves this folder.
- `build-tools/` — the scripts used to mirror the Hairise (WordPress / ThemeHT) theme and apply the brand (copy, colours, fonts, images).

Built on the Hairise (WordPress / ThemeHT) theme layout. The theme is a paid product: keep this repository private and hold a licence before using it in production.
